# InterviewPreparation

## Prerequisites
- .NET 10 SDK

## Run the async number-to-string snippet
The snippet is implemented in `AsyncNumberToStringRunner` and wired into the console menu as **Option 5**.

```bash
dotnet run --project Client/Client.csproj
```

When prompted, enter:

```text
5
```

Expected output:

```text
1 2 3 4
```
